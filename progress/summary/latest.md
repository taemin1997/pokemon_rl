# 최신 요약 (기준일 2026-10-14)

> 표시: [A] 트랙 A 자율학습 연구 / [B] 트랙 B 전당등록 진행. 시드별 결과는 따로 적음 (합치지 않음)
> (평가) = 학습 끝난 모델을 진단 도구로 잰 값, (학습) = 학습 중 지표 (판정에 안 씀), (가설) = 확인 안 된 해석

### 1. 목표와 원칙
- **가장 큰 목표 (10-10, 사용자 결정): 트랙 A** — 사람은 최종 목표만 주고, AI가 중간 목표 설정 → 탐색 → 학습 → 실행까지 스스로
- **트랙 B**: 전당등록 진행 (사람이 계획, AI가 실행). 트랙 A의 실전 무대이자 기준선. 결과마다 트랙을 표시하고 섞어서 "AI가 다 했다"고 하지 않음
- 진행: M1 ✅, M2a ✅, **M2b는 16구간 길 찾기·보존 ✅ / 통합 ⚠️**. 현재 [A] E26 1단계 재현성 완료 (10-14 재검증: 10-13과 판별로 같음), **2단계 기준선 완료: M2B E-lab 실패 78~86% / E-violet 48~58%**
- **RL 중심**: 버튼은 RL이 고름. BFS 시연·세이브 상태·매크로·규칙은 비계로 명시하고 하나씩 걷어냄
- **보상 최소화**: 길 찾기 보상은 "목표 도착 +10" 하나. 수풀/전투/전멸 벌점 없음 (전멸은 지표로만)
- **평가는 실제 결과로**: 진단 지표 (길 찾기 실패율, 경로 밖, 통합 실행). 판정 기준은 결과 보기 전에 `notes/experiments/E*.md`에

### 2. 모델링
| 요소 | 내용 |
|---|---|
| 알고리즘 | PPO (Stable-Baselines3), 환경 6개 병렬, CPU |
| 관찰 | 화면 흑백 72×80 + **목표 맵 (`--goal`, 원핫)**. 선택: 기억 (`--memory`) |
| 신경망 | CNN + **은닉층 256-256 (`--hidden 256,256`)** — 목표가 화면과 엮이려면 필요 (GOAL1 실패 원인) |
| 행동 | 상하좌우 + A + B, **1칸 조작** (`--move tile`) |
| 보상 | 도착 +10 (`goal_only`) |
| 커리큘럼 | 역방향 시연 (목표 근처 → 입구 쪽으로) + 경로 옆 시작. **여러 구간을 판마다 뽑아 정책 하나로** (`MultiSegmentEnv`: M2a 11구간, M2b 16구간) |
| 시연 경로 | 트랙 B = BFS, 트랙 A = Go-Explore (BFS 없이 찾은 경로) |
| 통합 실행 | `train/run_story.py`: 상위 계획 (맵 그래프 → 다음 목표 맵) + 길 찾기 정책 + 회복 규칙 + 이벤트/전투 매크로 |

### 5. RL vs 비계 (사람 도움, 숨기지 않음)
| RL이 하는 것 | 비계 (사람/규칙) |
|---|---|
| 걷는 동안 버튼 선택 전부 (구간 16개, 목표 맵에 따라 방향 바꿈) | **BFS 시연 경로** (트랙 B 학습의 연습 위치) — 트랙 A는 Go-Explore로 대체 시험 중 |
| 턱, U턴, 수풀, 문 찾기, 경로 밖 복구 | **세이브 상태 시작** (구간 시작·경로 밖 시작), 구간 밖 = 판 종료 |
| | **최종 목표 맵 순서** (사람). 그 사이 맵 순서는 맵 그래프에서 자동 (`envs/planner.py`) |
| | **회복 규칙**: 새 마을 첫 도착 / HP 절반 미만 / 공격 기술 PP 0 → 센터 (`should_heal`), 센터 안 회복 매크로 |
| | **이벤트 매크로** (`envs/menu.py`): 대화 넘기기, 이름 입력, 트레이너 시야 잠김 (`auto_event`). 공박사 대화·연구소/할아버지 집 안 규칙 걸음 (run_story) |
| | **전투**: A 연타 자동 + PP 0이면 PP 남은 공격 기술 / 야생 도망 (규칙). 기술 판단 RL은 아직 없음 |
| | 거리표: 진단 지표 전용 (보상 아님) |
