# 2단계: PyBoy 메모리 읽기, 한국어판 주소 검증

**상태**: ✅ 필요한 만큼 완료 (새로 필요한 주소는 그때그때 같은 방식으로 추가)

## 목표
보상, 관찰, 판정에 쓸 게임 값을 메모리에서 정확히 읽기
영문판 심볼(pret/pokegold)을 그대로 믿지 않고, 화면 값과 대조해서 검증

## 완료한 것
- [x] 영문판 주소가 한국어판에서 전부 틀린다는 것 확인 (맵 `247:247` 같은 쓰레기 값)
- [x] 원인 파악: 한국어 문자열이 2바이트라 버퍼가 길어지면서 뒤 변수가 밀림 (구간마다 밀린 양이 다름)
- [x] 찾는 방법 확립: 화면 값 패턴 검색, 움직이면서 바뀌는 바이트 찾기, 전후 비교, **반대 상황에서 꺼지는지 확인**
- [x] 검증 완료 주소 18개 + 전투 4개 (10-07: 적 HP/최대 HP, 메뉴 블록, 메뉴 커서) (`envs/memory_map.py`, 상세는 `notes/02_memory_map.md`)

| 구간 | 영문판 대비 | 주소 |
|---|---|---|
| 트레이너 정보 | +0xBB | ID |
| 돈 근처 | +0xB3 | 소지금 |
| 전투 | +0xBD | 전투 모드, 적 종, 적 레벨 |
| 맵/파티 | +0xFD | 맵 그룹/번호, X/Y, 파티 수/종, 파티1 종/레벨/경험치/HP/최대 HP/기술 4칸/지닌 물건 |

- [x] 기술 번호, 아이템 번호 체계가 영문판(pret)과 같음 → ROM 표를 번호로 바로 찾을 수 있음
- [x] 실수 기록: 전투 플래그를 처음에 대화창 플래그(D21B)로 잘못 찾음 → 반대 상황(대화창)에서 꺼지는지 확인해서 D1D3으로 바로잡음

## 부족한 점
| 우선순위 | 내용 | 언제 필요한가 |
|---|---|---|
| 높음 | **배지 주소(D62F) 미검증**: 추정만 함 | 최종 목표 판정. 첫 배지 전엔 확인 불가 → 사람이 체육관을 깬 세이브로 확인하는 방법도 고려 |
| ~~높음~~ | ~~적 HP 주소 없음~~ | D1BC / D1BE로 검증 (10-07) |
| ~~높음~~ | ~~전투 메뉴 커서 주소 없음~~ | 메뉴 블록 CEAD~CEB6, `battle_menu()` (10-07). 기술 3~4개, 트레이너 전투는 미확인 |
| ~~중간~~ | ~~내 포켓몬 HP 주소 없음~~ | DB49 / DB4B로 검증 (20/20) |
| ~~중간~~ | ~~전멸 감지 방법 없음~~ | 전투 중 파티 HP 합이 0이면 전멸 (`read_party_hp_total`) |
| 중간 | 트레이너 전투 값(2) 미확인 | 체육관 전투 구분 |
| 중간 | 스프레이 남은 걸음 (영문판 `wRepelEffect`) | 스프레이 효과 측정/사용 |
| 낮음 | 파티 2번째 이후 (구조체 크기 0x30 추정) | 포켓몬을 잡게 되면 |
| 낮음 | D21B(대화창 플래그)의 정확한 의미 | 대화/메뉴에 갇힌 시간 측정 |
| 낮음 | `step2_pyboy/01_read_memory.py`가 주소를 따로 들고 있음 | 주소를 고칠 때 두 곳 |
