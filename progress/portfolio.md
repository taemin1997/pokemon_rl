# 포트폴리오 정리

**상태**: 🔄 재료 수집 중 (마지막 갱신 2026-10-08)

## 이 프로젝트의 이야기 (지금까지 기준)
1. **역분석**: 한국어판 금 버전은 영문 메모리 자료가 안 맞음 → 직접 찾고 검증. 전투 플래그를 잘못 찾았다가 "반대 상황에서 꺼지는지"를 확인해서 바로잡은 과정까지
2. **순수 탐험 RL의 한계**: 탐험 보상 PPO로 시작 근처는 정복하지만 1M 스텝에서 정체
3. **진단으로 원인 분해**: "막다른 길 + 기억 부족" 가설을 거리표로 반증 → 실제 원인은 마을 복귀 정책 편향 + 풀숲 전투 비용
4. **병목이 하나씩 이동**: 환경 정리(A2)로 풀숲 통과 → 다음 병목 U턴. 그 과정에서 reward hacking을 직접 겪고 고침
5. **선생님 있는 학습**: 거리 보상(B)으로 U턴 통과, 보상 역할 정리(B2)로 88~96% 도착 + 뜸 들이기 → 전멸 인과 확인
6. **선생님 없는 학습**: 역방향 커리큘럼 RC/RC2(확산), AC 계열(아카이브)이 전부 U턴에서 멈춤 → 시연 경로를 따라 전선을 당기는 DEMO도 0%
7. **행동 단위가 병목**: DEMO 걸음의 56%가 제자리 회전 → 1칸 조작으로 바꾸자 0% → 88~100%, 거리 보상 없이 B2 수준 (시드 2개)
8. **"외웠나, 배웠나" 검증**: 경로 밖 진단(목표 거리 맞춘 짝 비교)으로 "경로 주변만 앎"을 발견 → 경로 옆 시작으로 학습에서 뺀 지역 2~55% → 77~84% (시드 2개)
9. **이어 붙이기와 전이**: 집 → 무궁시티 구간 모델 이어 붙이기 96%. 가중치 이어받기는 오히려 느리고 앞 구간을 잊음 → 섞어 학습
10. **관찰 설계**: 짧은 기억이 혼동 통로를 풂(1/12 → 6/12, "어디서 왔나" 단서). 목표 정보로 같은 길 양방향 (GOAL1, 진행 중)
11. **모듈 분리**: 길찾기와 전투를 정책으로 분리, 보상을 섞지 않음. 전투 매크로 + ROM 표 + 규칙 → RL
12. (앞으로) 모델 하나로 여러 구간, BFS 비계 걷기(Go-Explore 시연), 트레이너/체육관 전투, 전당등록까지

## 핵심 서사: 원인이 다른 실패를 실험으로 구별 (외부 검토 10-08)
1. **행동 인터페이스**: DEMO 0% → DEMO_TILE 88% (조작 방식만 바꿈)
2. **학습 시작 상태 분포**: OFFPATH1에서 경로 밖 붕괴 발견 → LAT1으로 빼둔 지역 77~84%
3. **목표와 관찰의 결합**: GOAL1 실패 (선형 결합 → 상수 쏠림) → GOAL2 (결합 뒤 은닉층)로 검증 중
- 하이퍼파라미터를 바꿔가며 찍는 대신, 실패마다 원인 가설을 세우고 하나만 바꿔 확인

## 차별점
- 2세대 한국어판 메모리 역분석 (영문 자료로는 안 되는 부분)
- 가설 → 판정 기준 → 실험 → 결과를 **학습 전에 먼저 적고**, 한 번에 하나만 바꾸는 방식
- 실패한 실험도 기록하고 다음 설계의 근거로 씀 (v2, A, A3, RC, RC2)
- 숫자 지표 너머의 행동 분석 도구 (히트맵, 거리표, 진단 평가, 턱 분석)
- CPU 한 대 제약 안에서 커리큘럼, 보상 설계로 풀어가는 과정
- 비계(BFS, 규칙, 세이브 스테이트)와 RL의 역할을 명확히 나누고, 비계를 하나씩 걷어내는 구조

- 쓰지 말 표현: "경로 암기를 극복했다" (학습한 맵 안 근거만 있음, 새 맵 제로샷 0%), "자율 플레이" (목표·구간·이벤트는 사람)
