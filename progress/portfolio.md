# 포트폴리오 정리

**상태**: ⬜ 재료 수집 중

## 이 프로젝트의 이야기 (지금까지 기준)
1. **역분석**: 한국어판 금 버전은 영문 메모리 자료가 안 맞음 → 직접 찾고 검증. 전투 플래그를 잘못 찾았다가 "반대 상황에서 꺼지는지"를 확인해서 바로잡은 과정까지
2. **순수 탐험 RL의 한계**: 탐험 보상 PPO로 시작 근처는 정복하지만 1M 스텝에서 정체
3. **진단으로 원인 분해**: "막다른 길 + 기억 부족" 가설을 거리표로 반증 → 실제 원인은 마을 복귀 정책 편향 + 풀숲 전투 비용
4. **병목이 하나씩 이동**: 환경 정리(A2)로 풀숲 통과 → 다음 병목 U턴. 그 과정에서 reward hacking을 직접 겪고 고침
5. **선생님 있는 학습**: 거리 보상(B)으로 U턴 통과, 보상 역할 정리(B2)로 88~96% 도착 + 뜸 들이기 → 전멸 인과 확인
6. **선생님 없는 학습**: 역방향 커리큘럼 RC/RC2 실패(확산) → Go-Explore식 아카이브(AC) (← 진행 중)
7. (앞으로) 여러 구간 한 정책 + 안 배운 구간 시험으로 "길 찾는 법"을 배웠는지 증명
8. (앞으로) 전투, 회복, 포획을 비계에서 RL로 하나씩 넘기며 전당등록까지

## 차별점
- 2세대 한국어판 메모리 역분석 (영문 자료로는 안 되는 부분)
- 가설 → 판정 기준 → 실험 → 결과를 **학습 전에 먼저 적고**, 한 번에 하나만 바꾸는 방식
- 실패한 실험도 기록하고 다음 설계의 근거로 씀 (v2, A, A3, RC, RC2)
- 숫자 지표 너머의 행동 분석 도구 (히트맵, 거리표, 진단 평가, 턱 분석)
- CPU 한 대 제약 안에서 커리큘럼, 보상 설계로 풀어가는 과정
- 비계(BFS, 규칙, 세이브 스테이트)와 RL의 역할을 명확히 나누고, 비계를 하나씩 걷어내는 구조
