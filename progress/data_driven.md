## 전투 모듈은 ROM 데이터로

게임 안에도 상대 트레이너 AI가 기술을 고르는 루틴이 있을 만큼, 규칙 기반 기술 선택은 충분히 코드로 짤 수 있음. 다만 기술 표를 손으로 적지 않고 **ROM에서 읽음**:

| 필요한 데이터 | 가져오는 방법 |
|---|---|
| 내 포켓몬 기술 번호, PP, 능력치 | 게임 메모리 (파티 구조체, 지금까지 검증한 +0xFD 구간) |
| 상대 포켓몬 종, 레벨, HP | 게임 메모리 (적 구조체, +0xBD 구간) |
| 기술 위력/타입/명중률 | ROM의 기술 표. 위치는 이미 아는 기술 값(예: 몸통박치기 = 노말, 위력 35)으로 바이트 패턴 검색 → 한국어판에서도 자동으로 찾음 |
| 타입 상성표 | ROM의 상성 표. 같은 방식 (알려진 상성 몇 개로 패턴 검색) |
| 종족값, 타입 | ROM의 종족값 표. 리아코 값을 화면/메모리 능력치와 대조해서 검증 |
| 레벨업 기술 | ROM의 레벨업 기술 표 |

기술 선택 규칙: `기대 데미지 = 위력 × 명중률 × 자속(1.5) × (물리면 공격, 특수면 특수공격) × 상성`이 가장 큰 기술 (2세대는 타입으로 물리/특수가 정해짐). 기술 교체도 같은 값으로 가장 낮은 기술을 버림

검증 방법: 몇몇 기술/상성은 사람이 알고 있는 값과 대조 (손으로 적는 건 이 "검증용 정답"뿐)
