```

공박사 연구소 ← 연두마을 ← 29번도로 ← 무궁시티 [라이벌전 ③] ← 30번도로 ←┘
```

## 전멸 대응 (10-08)
- 원칙: 전멸은 지표로만, 최종 플레이는 부활 위치에서 이어감
- 실제 확인: 29번도로 전투에서 HP를 1로 써넣고 짐 → "싸울 수 있는 포켓몬이 없다" → **집 2층 (24,7,3,3)**, HP 가득(22), 돈 절반 (3000 → 1500). 상태 `states/segments/respawn_home.state`
- 구간 `house2f`: 집 2층 → 계단 → 집 1층, 최단 7걸음, 시연 7, 경로 밖 32칸
  - 버그 수정: 시연 녹화 중 "맵이 바뀌는 방향 찾기"가 기다리지 않고 좌표를 읽어서 계단 방향을 못 찾음 → settle=SETTLE (`walk_to_goal`)
- `envs/planner.py`: 구간 edges에서 맵이 바뀌는 이동만 모아 맵 연결 그래프 → BFS로 맵 순서. 예: 집 2층 → 집 1층 → 연두마을 → 29번도로 → 무궁시티 / 할아버지 집 → 30번도로 → 무궁시티 → 29번도로 → 연두마을 → 연구소
- 남은 것: 포켓몬센터에서 회복하면 부활 위치가 센터가 됨 → 센터 안 → 마을 구간 + 간호사 대화 매크로 (회복 판단은 나중에)

## 회복 규칙 (10-08, 사용자 제안: 새 마을에 가면 한 번 회복을 기본으로)
- 규칙 (상위 계획, 비계): **새 마을(센터 있음) 첫 도착이면 회복** (부활 위치 갱신) + **다시 지날 땐 HP 절반 미만일 때만**. 연두마을엔 센터 없음 → 무궁시티가 첫 센터. "언제 회복할지"는 나중에 RL 후보
- 구간: `cherrygrove_pc` 무궁시티 → 센터 (최단 14), `cherrygrove_pc_exit` 센터 안 → 무궁시티 (최단 5)
- 매크로 `envs/heal.py` `heal_at_pc`: 문에서 위로 카운터까지 → A + 매번 움직임 확인. 시험: **A 17번, HP 16 → 22(최대)**. 기본 선택 '예'라 A만으로 됨
- 미확인: 센터 회복 후 전멸하면 그 센터에서 부활하는지 (게임 규칙상 그래야 함) → 다음에 실제로 확인
- **자동 회복 판단 (10-08, 사용자: "피 상황이 별로면 알아서 회복")**: `envs/planner.py` `should_heal` — 센터 있는 마을 첫 도착이면 회복, 그 밖엔 HP < 50%면 `nearest_pc`(맵 그래프로 가장 가까운 센터, 센터 맵은 맵 이름표에서 판별)로. 상위 계획 규칙(비계)
  - 다음 단계 (비계 걷기 후보): 상위 RL이 "계속 / 회복" 선택. 보상은 최종 목표에 빨리 도착 하나 (전멸은 부활 위치에서 다시 와야 해서 자연히 손해 → 전멸 벌점 불필요). 구간 하나 = 한 스텝인 작은 환경 + 실측 HP 소모 분포로 빠르게 학습, 규칙이 기준선
