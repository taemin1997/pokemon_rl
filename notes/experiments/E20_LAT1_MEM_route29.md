# LAT1_MEM_route29 (LAT1 + 짧은 기억) — DEMO_TILE_MEM을 대체

> 실험 기록 (가설, 판정 기준, 결과, 해석). 공통 조건은 `notes/04_experiments.md`

- **왜**: LAT1로 분포 문제는 풀렸지만 "벽에 막히면 계속 뚫으려 함"(사용자 라이브 관찰)이 남음. 남은 경로 밖 실패 3칸도 막다른 끝에서 같은 방향 반복. 경로 옆 시작이 기본 커리큘럼이 됐으니 기억 실험도 그 위에서 함 (DEMO_TILE_MEM은 안 돌리고 이걸로 대체)
- **바꾼 것**: 관찰만 (`--memory`: 직전 버튼 원핫 6 + 직전 걸음에 움직였나 1). 커리큘럼 `route29_demo_lat`, 보상, 조작, PPO, 시드 LAT1과 같음
- **기준선 (학습 전 측정, 10-07, `train.offpath stuck route29 ... --workers 2`)**: OFFPATH 진단 칸 64개(경로 밖 32 + 짝)에서 1판씩. 방향 버튼 걸음 중 전투가 끼지 않은 걸음만 셈

| 정책 | 도착 | 막힌 비율 | 막힌 직후 같은 버튼 | 최장 연속 막힘 (중앙 / 최대) |
|---|---|---|---|---|
| LAT1 (시드0) | 95% | 30% | **43%** | 4 / 14 |
| DEMO_TILE (시드0) | 75% | 28% | 27% | 3 / 14 |

  - 6개 버튼 균등이면 "막힌 직후 같은 버튼"은 약 17%. LAT1은 길은 더 잘 찾지만 막혔을 때 더 고집함 (정책이 더 확신)
- **가설**: 막힌 걸 모르는 게 고집의 원인이면, 기억을 주면 막힌 직후 같은 버튼 비율과 최장 연속이 줄고, aliasing 통로 3칸((16,10), (15,12), (20,11), LAT1 0/4)에서 빠져나옴
- **판정 기준** (LAT1 시드 0/1과 같은 실행에서)
  - 확인용 (행동): 막힌 직후 같은 버튼 43% → 25% 아래, 최장 연속 중앙값 감소. 안 줄면 정보를 안 씀 → 기억 형태 재검토 (연속 막힘 횟수 추가, 프레임 쌓기)
  - 주: aliasing 통로 3칸 도착 0/12 → 6/12 이상, 빼둔 지역 ≥ LAT1 − 10%p 유지, 경로 위 ≥ 80%
  - 막힘은 줄었는데 통로 3칸은 그대로 → 그 칸들은 "막힘"이 아니라 "방향을 모름"(목표/위치 정보 문제) → 목표 정보 실험으로
- **결과** (10-08 판정. 30만 `final.zip`, `train.report`로 LAT1 두 시드와 같은 실행. 학습 중 입구 도달 19.0만 = LAT1 20.9 / 25.2만보다 빠름. 진단 도중 컴퓨터 절전으로 몇 시간 멈췄다 재개, 결과엔 영향 없음)

| 지표 | LAT1_MEM | LAT1 시드0 | LAT1 시드1 |
|---|---|---|---|
| 경로 위 start/S2/S3 | 100 / 96 / 88% | 96 / 96 / 96% | 100 / 96 / 100% |
| 반대 방향 | 0% | 0% | 0% |
| 경로 밖 3~5 / 6~9 / 10+ | 88 / 97 / 94% | 84 / 88 / 88% | 88 / 88 / 88% |
| 빼둔 지역 | **89%** | 77% | 80% |
| **혼동 통로 3칸** | **50% (6/12)** | 8% | 8% |
| 막힌 직후 같은 버튼 | 44% | 42% | 46% |
| 최장 연속 막힘 (중앙/최대) | 3 / 11 | 4 / 11 | 4 / 19 |
| 목표 바꾸면 행동 바뀜 | 0% | 0% | 0% |

- **판정**
  - 행동 기준 (막힌 직후 같은 버튼 < 25%): **미달 (44%)**. 기억이 "막히면 다른 걸 해본다"로는 안 쓰임
  - 주 기준 (혼동 통로 ≥ 6/12): **달성 (6/12, LAT1은 두 시드 1/12씩)**. 빼둔 지역 89% (+9~12%p, 오차 경계), 경로 위 ≥ 80% 유지
- **해석**: 기억이 고집을 줄인 게 아니라, 직전 행동 = "어느 쪽에서 왔나"가 비슷한 화면을 구분하는 단서가 된 것으로 보임 (혼동 통로는 화면이 동쪽/위가 정답인 곳과 비슷해서 반대로 가던 곳). 외부 검토의 "어디서 왔는지 알려주기"와 맞음. 사전 기준의 두 갈래 중 "막힘은 그대로인데 통로는 풀림" → 통로 실패의 원인은 막힘이 아니라 방향 혼동
  - 시드 1개, 통로는 12판 → 경향으로만. 벽 고집(44%)은 여전히 남음 → 다음 후보: 연속 막힘 횟수, 프레임/행동 여러 개 쌓기 (보상 벌점은 계속 보류)
- **결정**: GOAL1은 설계대로 기억 없이 진행 (한 번에 하나). 기억은 GOAL1 뒤 목표 + 기억 조합으로
