## 질문
- E30 D(확신 상태 KL)는 수리 **한 번**(r1)에서만 확인됨. 수리가 r1 → r2 → r3로 이어져도 막히나
- 세 가설을 따로 판정 (사용자 요청 10-22)
  1. **연쇄 보존**: r1 → r2 → r3 뒤에도 기존 구간 성공률이 유지되나
  2. **새 구간 학습**: 옛 행동을 붙잡는 제약이 새 구간 학습 자체를 막지 않나 (앵커가 커질수록 더 위험)
  3. **확장 비용**: 수리 횟수에 따라 앵커 수·학습 시간·저장량이 얼마나 느나
- 덧붙여 E30에서 못 답한 것: 앵커가 시연 경로의 87%(517/594칸)였음 → **정말 소수 상태만으로 되나**

## 설계 원칙: 둘로 나눔
- 자율 루프에선 조건마다 수리 순서가 달라짐 (E26: r1이 route29를 깨뜨려서 r2가 route29를 고침. D면 route29가 안 깨져 r2가 다른 곳으로 감) → 군끼리 같은 과제가 아님
- **E31a (통제)**: 새 구간 순서를 미리 고정하고 학습 방법만 바꿈 → 세 가설 판정
- **E31b (자율)**: E31a에서 이긴 조건 하나만 E26 자동 복구 루프에 넣어 무인 재도전까지 → '실제로 전진하나' 확인 (연구 판정 아님, 진척·자율성 지표로 기록)
