# CHAIN1 (구간 이어 붙이기 검증: 연두마을 → 29번도로 → 무궁시티) + T1 (첫 전이 실험)

> 실험 기록 (가설, 판정 기준, 결과, 해석). 공통 조건은 `notes/04_experiments.md`

- **왜**: route29 구간은 29번도로 입구(59,9)에서 시작함. "연두마을에서 무궁시티까지"가 되려면 앞 구간을 붙여서 한 판으로 이어지는지 확인해야 함
- **새 구간 `newbark`**: 집 1층 (9,2) → 29번도로 진입. 허용 맵: 집 1층, 연두마을 (연구소/옆집/2층 = 실패). BFS 219칸, 최단 24걸음, 시연 25칸 (전투 0, HP 20). 이벤트로 막힌 곳 없음
- **실험 1 — 연두마을 학습 (T1 전이)**: DEMO_TILE 방식 (`route29_demo`와 같은 커리큘럼 규칙, `goal_only`, `--move tile`) 두 가지를 같은 예산(10만)으로
  - (a) `NB_scratch`: 처음부터
  - (b) `NB_init29`: 29번도로 DEMO_TILE(시드 0) 가중치에서 시작 (`--init`). 바꾼 건 초기 가중치 하나
  - 가설: 29번도로에서 배운 "걷는 능력"(1칸 이동, 막힌 곳 벗어나기, 문/통로)이 번진다면 (b)가 80% 도달까지 확실히 빠름
  - 판정: 학습 중 전선이 입구(24)에 닿는 스텝, 진단 80% 도달 체크포인트. (b)가 절반 이하 스텝이면 전이 있음 / 비슷하면 이 짧은 구간에선 전이 효과가 안 보임 (마을은 쉬워서 처음부터도 빨리 배울 수 있음 → 30번도로에서 다시)
  - 주의: 마을은 짧고 전투가 없어 쉬운 구간이라 전이 차이가 작게 나올 수 있음. 화면 무늬(집, 마을)도 29번도로와 다름
  - **0스텝 기준점 (학습 전 측정, 10-07)**: `train.diagnose newbark models/DEMO_TILE_route29/final.zip random`, 25판
    | 정책 | 도착률 | 진행 p50/p90/최대 | 이탈 |
    |---|---|---|---|
    | DEMO_TILE_route29 (그대로) | 0% | 2 / 2 / 4 | 0% |
    | random | 0% | 5 / 10 / 16 | 44% (연구소/옆집/2층) |
    - 29번도로 모델은 집 1층에서 **무작위보다도 못 움직임** (2칸 근처에서 갇힘). "걷는 능력"이 화면만 바뀌어도 그대로 번지진 않음
    - 그래서 (b)가 빠르다면 그건 "처음부터 잘해서"가 아니라 "다시 배우는 속도가 빨라서"임. 커리큘럼이 목표 근처(29번도로 입구 앞)부터 시작하니 집 1층 0%는 학습 초반엔 영향이 작을 수 있음
  - **학습 중 관찰 (NB_scratch 4.9만)**: 전선 25(집 1층) 도달 **3.7만**. 이후 실제 입구 판 도착 86~100%, 도착 걸음 82 → 37 (최단 24)로 줄어드는 중. 전투/전멸 0
    - 전선은 롤아웃(3,072스텝)마다 최대 3칸만 당겨짐 → 25칸이면 **최소 약 2.7만**. scratch는 롤아웃 12번 중 9번 당김 (정체 3번) → 이미 하한 근처
  - NB_scratch 끝 (10만, 약 11분): 4.9만 이후 실제 입구 판 도착 매 기록 100%, 도착 걸음 37 → 6.7만에 23 근처에서 수렴 (최단 24. 전선 판엔 1~2칸 앞에서 시작하는 판이 섞여 평균이 24보다 약간 작음). 5만 이후는 굳히기만 함
  - **학습 중 관찰 (NB_init29 2.5만)**: 사용자 관찰 "막힌 걸 돌아서 가는 판단을 못 함"과 수치가 맞음
    - 전선 16 = 시연 9번 칸 (연두마을, 집 문 바로 앞 (13,6)). 경로는 여기서 아래로 1칸 → 7번째 줄을 따라 서쪽. 전선 판 도착률 100% → 81 → 67 → **54%**로 떨어지는 중, 판 길이 37 → 162 (scratch 같은 스텝 84)
    - 초반엔 전선이 scratch보다 빨랐음 (2.15만에 16 vs 13) → 집 안/짧은 직선은 빨리 됨. 문 밖에서 "막히면 돌아가기"가 필요한 곳에서 느려짐
    - 엔트로피 −1.1~−1.4 (scratch −1.5~−1.8, 6개 버튼 균등이면 −1.79) → 29번도로에서 굳은 정책이라 **덜 무작위로 시도함**. 막힌 방향을 계속 밀고 다른 방향을 우연히 해볼 확률이 낮음. 가설: 부정적 전이의 원인은 "29번도로 습관(서쪽 밀기)" + "낮은 탐험"
    - 아직 학습 중. 판정은 진단으로 (NB_init29 돌리기 전, scratch 곡선을 본 뒤라 명시)**: "전선 도달 스텝 절반 이하"는 당기기 속도 하한 때문에 구조적으로 불가능 (3.7만의 절반 1.85만 < 하한 2.7만). 그래서 바꿈
    - 주 기준: **같은 체크포인트(5만)를 집 1층 진단**에서 비교 (도착률, 도착 걸음). (b)가 도착 걸음이 확실히 짧거나 도착률 +10%p 넘게 → 전이 있음
    - 보조: 전선이 멈춘 롤아웃 수 (scratch 3/12), 전선 25 도달 스텝 (하한 2.7만과의 거리)
    - 둘 다 비슷 → 이 구간은 쉬워서 처음부터도 당기기 속도만큼 배움. 전이 측정은 30번도로처럼 긴 구간에서 (당기기 속도 상한이 병목이 아닌 곳)
- **실험 2 — 끝까지 평가 (집 1층 → 무궁시티 한 판)**: 평가용 구간 `newbark_cherrygrove` (허용: 집 1층, 연두마을, 29번도로 / 목표: 무궁시티)
  - (i) 이어 붙이기: 지금 맵이 연두마을 쪽이면 연두마을 모델, 29번도로면 29번도로 모델 (구간 경계에서 교체 = 사람이 정한 상위 계획)
  - (ii) `NB_init29` 하나로 끝까지: 연두마을을 배우면서 29번도로를 잊었나 (catastrophic forgetting)
  - 판정: (i) 도착률이 route29 단독 진단(80~88%)에서 크게 안 떨어지면 → 이어 붙이기 성공 (29번도로 모델이 고정 입구 상태가 아닌, 앞 정책이 만든 입구 상태에서도 됨)
  - (ii)가 29번도로 구간에서 크게 떨어지면 → 한 구간씩 이어 학습하면 앞을 잊음 → 여러 구간 섞어 학습(V5)의 근거
- **결과** (10-07. NB_init29는 약 7.4만에서 프로세스가 꺼짐 → `final.zip` 없음, 마지막 `live.zip`(약 7.4만)으로 평가. 위치당 25판)
  - 학습 곡선: 전선 25 도달 scratch **3.7만** / init29 **5.8만**. init29는 전선 16(문 밖, 2.15~2.8만)과 19(집 1층 안, 3.1~4.6만)에서 정체, 전선 판 도착 44~50%, 판 길이 최대 273

- **판정**
  - T1 (수정한 주 기준: 5만 체크포인트): init29 24% vs scratch 100% → **부정적 전이**. 29번도로 가중치에서 시작하면 오히려 느림 (전선 도달 3.7만 → 5.8만). 보조 기준도 같은 방향 (전선 정체 롤아웃 scratch 3 / init29 약 9)
  - CHAIN1 (i): 96% (route29 단독 80~88%보다 낮지 않음) → **이어 붙이기 성공. 집 1층 → 무궁시티 거리 보상 없이 96%**. 29번도로 모델이 앞 정책이 만든 입구 상태에서도 그대로 됨
  - CHAIN1 (ii): 28%, 실패는 전부 시간 초과 (이탈 0, 전멸 0), 진행 p50 68 = 29번도로 약 44걸음 = U턴 근처 → **연두마을을 배우면서 29번도로 U턴을 잊음** (catastrophic forgetting)
- **해석**
  - 가중치 이어받기는 이 조건에서 "능력 이전"이 아니라 "습관 이전". 29번도로에서 굳은 정책(엔트로피 낮음)은 새 장소에서 막히면 다른 방향을 덜 시도함 → 돌아가야 하는 자리(문 밖, 집 안 모서리)에서 오래 정체
  - 그리고 새 구간을 배우면 옛 구간을 잊음. 둘 다 "한 구간씩 차례로 이어 학습"이 안 맞는다는 근거 → **여러 구간 섞어 학습**(같은 롤아웃에 연두마을 판과 29번도로 판을 같이)으로 가야 "모델 하나가 여러 구간을" 원칙을 지킬 수 있음
  - 이어 붙이기 96%는 구간 경계에서 모델을 바꾸는 사람의 상위 계획(구간 순서)이 비계. RL: 각 구간 안의 걷기 전부
  - 시드 1개, 이 비교는 짧은 구간 하나라 일반 결론은 아님. 다만 차이(24 vs 100%, 28 vs 96%)는 오차(±10%p)보다 훨씬 큼
  - 주의: init29 평가는 7.4만 모델이라 scratch 10만과 스텝이 다름. (ii)를 10만으로 다시 재도 U턴을 잊은 건 연두마을 학습 중에 생긴 일이라 결론은 같을 것으로 봄 (확인하려면 `--resume latest --total-steps 100000`)
