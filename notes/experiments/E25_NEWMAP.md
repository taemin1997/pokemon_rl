# NEWMAP (트랙 A): 처음 보는 맵(30번도로 돌아오는 길)을 무엇으로, 얼마나 빨리 배우나

> ZS30(E24)에서 GOAL2 zero-shot 0% → 그럼 기존 학습이 **새 맵 학습을 빠르게** 해주긴 하나? 그리고 BFS 시연이 꼭 필요한가?
> **핵심 질문 (사용자, 10-08)**: 처음 보는 맵에서 실패한 자기 경험만으로 다시 학습하면 이전보다 빠르게 적응하나? → 되면 "경로를 배우는 AI"에서 "경험으로 새 지역에 적응하는 AI"로

- **대상**: `route30_rev` (할아버지 집 앞 → 무궁시티, 최단 59). 목표(무궁시티)는 GOAL2가 본 것 → 원핫 문제 없음
- **공통**: 보상 `goal_only`, tile, `--goal --hidden 256,256` (구조 같게), 시드 0, 수정 코드, 예산 20만, 경로 옆 시작 없음 (시연 출처만 비교하려고)
- **실험** (외부 검토 표)

| 이름 | 초기 정책 | 연습 시작 위치 | 보는 것 |
|---|---|---|---|
| NM0 | GOAL2 | 실제 출발만 (`--env route30_rev`) | 커리큘럼 없이 순수 RL로 되나 |
| NM_D | GOAL2 | BFS 시연 (`route30_rev_demo`) | 지금 방식 기준선 |
| NM_B | GOAL2 | Go-Explore 경로 (`route30_rev_demo_ge`, BFS/지도 없음) | BFS 없이 같은 수준인가 |
| NM_C | 랜덤 | Go-Explore 경로 | 기존 학습의 전이 효과 (B와 비교) |

- **지표**: 체크포인트(5만마다)를 `train.diagnose route30_rev` 25판으로 → **도착 80% 처음 도달 스텝**. 20만까지 못 가면 "20만 초과"
- **판정 기준 (실행 전 10-08 16:10)**
  - B ≤ D × 1.5 스텝 (오차 감안) → BFS 시연 없이도 비슷하게 배움 → 트랙 A에서 BFS 의존 낮음
  - B < C × 0.5 스텝 → 기존 학습(GOAL2)이 새 맵 학습을 확실히 빠르게 함 (전이 있음). 비슷하면 전이 없음
  - B0가 80% 도달 → 커리큘럼조차 필요 없음 (예상은 실패: A3에서 도착 보상만으론 신호가 안 닿았음)
  - 시드 1개라 차이가 2배 이내면 "차이 불확실"로 씀
- **순서**: NM0 → NM_D → NM_B → NM_C (학습마다 약 40~60분, 하나씩)
- **B0가 실패하면 (예상)**: 도착 보상만이면 실패한 판은 보상 0 → 배울 신호 없음 (A3). 지도/BFS 없이 자기 경험을 쓰는 후보:
  1. 자기 경험 커리큘럼: 정책이 가본 칸 저장 → 목표에 가까웠던 칸에서 다시 시작 (AC3/Go-Explore를 정책 자신의 경험으로). **1순위**
  2. HER: 못 간 판을 "실제로 간 곳이 목표였던 성공"으로 다시 씀 (목표 표현이 맵보다 세밀해야 함)
  3. 호기심 보상: 처음 가본 칸에 작은 보상 (벽 밀기 감소, 넓게 탐색)
  - 각 방법을 GOAL2 초기 vs 랜덤 초기로 → GOAL2 쪽이 확실히 적은 스텝이면 "경험으로 적응하는 능력" 근거. 구간이 늘수록 새 구간 적응 스텝이 줄면 메타 학습에 가까움

## 수정 계획 (10-08 16:18, 외부 검토 2차 반영 — 결과 보기 전)
- **원칙**: 탐색기/커리큘럼에 목표 좌표, 지도, 정답 거리(BFS)를 주지 않음. 쓰는 건 "지금 칸이 어디인가"(맵, x, y = 상태 구분, Go-Explore 칸 표현과 같은 수준)와 "목표 맵에 들어왔나"뿐

- **방문 보상(B2) 주의 (우리 데이터)**: A(새 맵 보상 → 나갔다 들어오기 보상 구멍), B(새 칸 보상 → 목표 앞 뜸 들이기 → 전투/전멸 증가). β 아주 작게(칸당 약 0.01, 도착 +10), 판 안 / 학습 전체 방문 기록 구분 비교, **목표 무시 검사** (목표 근처 시작 판 도착률 하락 여부)

| NM1 | GOAL2 + 자기 경험 저장/재시작 (방문 적은 칸, 경계) | 탐색 범위 확대, 성공 발생 |
| NM2 | NM1 + 작은 방문 보상 | 탐색 + 실제 도착률 (목표 무시 검사) |

- 용어: 구간이 늘수록 적응 스텝이 줄어도 "메타 학습"이 아니라 **"전이 효과"**로 씀
