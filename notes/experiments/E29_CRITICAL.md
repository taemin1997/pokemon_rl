## 길목(결정적 상태) 정의 — 자동 규칙, 결과 보기 전에 고정
- 깨진 구간의 BFS 시연 경로 칸마다, 불러온 뒤 1프레임 그린 관찰로 두 정책의 행동 확률을 잼 (E28 F2와 같은 방법, `train/e29_critical.py`)
- **뒤집힌 칸 K** = 옛 정책 최빈 행동 확률 ≥ 0.8 이고, 새 정책 최빈 행동이 다르고, 새 정책이 옛 최빈 행동에 주는 확률 ≤ 0.5
- **대조 칸 K_ctrl** = 같은 시연 경로에서 뒤집히지 않은 칸 (옛 ≥ 0.8, 새 최빈 = 옛 최빈) 중 |K|개를 고정 시드로 뽑음
- 칸은 (맵 그룹, 맵 번호, x, y)로만 맞춤 (방향·이벤트 무시). 시연 경로 밖에서 새 정책이 들르는 칸은 덮어쓰지 않음

## 조건 (같은 시작 상태, 같은 판 시드 0~49, 시계 고정, 사례마다)
- **A** 옛 정책으로 끝까지 / **B** 새 정책으로 끝까지
- **C** 새 정책 + K 칸에 있을 때만 옛 정책 행동 (옛 정책이 그 관찰로 뽑음), 나머지는 새 정책
- **C_ctrl** 새 정책 + K_ctrl 칸에서만 옛 정책 행동
- 판마다 기록: 도착, K 도달 (K 칸을 한 번이라도 밟음), K 통과 (K 칸들 중 가장 목표에 가까운 칸보다 더 가까이 감), 덮어쓴 걸음 수, 걸음마다 KL(옛 ‖ 새) (평균, K 칸에서 평균)
- 판 수 50 (50판이면 50% 근처에서 ±2표준오차 ≈ ±14%p)

## 판단 기준 (제안 — 사용자 확인 뒤 확정)
- **인과 지지**: C − B ≥ +30%p **그리고** C ≥ A − 15%p **그리고** C_ctrl ≤ C − 20%p
- **부분 지지** (길목 + 다른 상태 누적): C − B ≥ +30%p 이지만 C < A − 15%p
- **기각**: C − B < +15%p (길목을 고쳐도 안 돌아옴 → 다른 상태 변화 누적)
- 그 사이 (+15 ~ +30%p): 판단 보류, 숫자만 보고
- 대조가 C만큼 회복시키면 (C_ctrl > C − 20%p) "특정 칸이 아니라 옛 정책 개입 자체의 효과" → 지지 아님
- 사례별로 따로 판정, 합치지 않음. 시간대는 고정 시계 하나 (밤은 후속 — 아래)
