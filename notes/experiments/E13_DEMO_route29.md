# DEMO_route29 (역방향 시연 학습: 전선이 좌표가 아니라 경로를 따라 움직임)

> 실험 기록 (가설, 판정 기준, 결과, 해석). 공통 조건은 `notes/04_experiments.md`

- **바꾼 것**: 시작 위치를 고르는 방식만 (보상 `goal_only`, PPO 설정 그대로, 거리표는 학습에 안 씀)
  - 시연: `build_segment route29 --demo`가 거리표를 따라 걸으며 지나간 칸의 상태 103개를 저장 (`states/segments/route29/demo.pkl`). 최단 경로와 같음 (남은 거리 103 → 1, 한 번도 안 늘어남). 전투는 타이밍을 바꿔 피함 → HP 18~20 (실제 입구 20)
  - 전선(ptr): 시연 번호. 판 시작은 [ptr, ptr+4] 중 무작위, 10%는 실제 입구
  - 당기기 (`DemoCurriculumCallback`): 롤아웃(3072스텝)마다 환경 6개 결과를 모아서, 전선 구간에서 시작한 판이 24개 이상이고 도착률 ≥ 50%면 ptr을 3걸음 입구 쪽으로. **전선 하나를 환경 6개가 같이 씀** (AC 계열은 환경마다 따로였음)
- **비계 명시**: 시연 경로는 BFS(거리표)가 찾은 것 = **선생님이 정답 경로를 한 번 보여준 것**. 다만 버튼(행동)은 안 주고, 보상/관찰에도 안 들어가고, "어디서 연습할지"에만 씀. 각 시작점에서 어떻게 걸을지는 RL이 도착 보상만으로 배움
  - 그래서 성공해도 결론은 "선생님 없이"가 아니라 **"매 걸음 방향 신호(B2) 대신 시연 1개 + 도착 보상으로 U턴을 넘음"**
- **장치 확인 (짧은 시험 9천 스텝)**: 전선 1 → 4 → 7걸음 (롤아웃마다 3씩), 전선 구간 도착률 85~100%, 실제 입구 도착 0%. 저장/이어서 하기 동작
- **가설**: AC3가 U턴에서 멈춘 원인이 "좌표 근처 = 다음 단계" 가정이라면, 전선이 경로를 따라 움직일 때 U턴(경로상 목표에서 약 50~68걸음: (40,8) → x=31 틈 → (33,16))을 지나 입구까지 갈 것
  - 반대로 U턴 구간에서 도착 보상만으로는 배우기 자체가 어렵다면(예: 턱 줄 아래에서 목표 반대 방향 서쪽 → 틈 → 동쪽), 전선이 경로를 따라가도 약 50~68에서 멈출 것
- **비교 대상**: AC3 250k (전선 약 50에서 정체, 입구 도착 0%, 진행 p50 0~5) / B2 (거리 보상) 88~96%
- **판정 기준** (250k, `train.diagnose route29`, AC3와 같은 진단)
  - S1 도착 ≥ 30% → 분기점 통과 (시연 1개 + 도착 보상으로 U턴을 넘음) → 시드 재확인 + 일반화 시험
  - `demo_front`가 70 이상(U턴 아래쪽 길 너머)으로 갔지만 S1 도착 < 30% → 방향 맞음, 학습량 부족 → 500k 연장
  - `demo_front`가 50~68(U턴 구간)에서 5만 스텝 넘게 정체 → **커리큘럼 방식이 아니라 U턴 자체가 도착 보상만으로 어려움** → U턴 미니 벤치마크(U턴 앞뒤 시작점만 떼서 시험)로 원인 분리
  - `demo_front`가 50도 못 감 (AC3보다 느림) → 당기기 규칙 문제 (min_eps, 성공 기준) → 조정
- **볼 지표**: `demo_front`(전선, 경로상 목표에서 몇 걸음), `demo_front_rate`(전선 구간 도착률, 50% 근처면 정상), `real_goal`, `start_dist`(분석용)
- **해석할 때 조심할 점**
  - 시연 상태는 고정된 103개라, 그 상태들(난수, NPC 위치 포함)에 맞춰 외울 수 있음 → 평가는 반드시 실제 시작 상태 진단(시작 프레임 흔듦)으로
  - 경로 밖으로 벗어난 상황은 연습이 적음 (시작이 전부 최단 경로 위). 실제 시작에서 한 번 벗어나면 회복을 못 할 수 있음 → 진단의 진행 p50/p90과 이탈로 확인
- 학습 중 관찰 (13.5만, 전선 64 = 턱 줄 아래 (31,14)~(33,16))
  - 전선 판 6번 중 5번이 **(27,10)에 갇혀 512걸음 끝까지 위/오른쪽/아래로 벽을 밈** (막힌 이동 약 90%, A/B 약 30%). 1번은 221걸음에 도착
  - (27,10)은 턱 줄 아래 길에서 서쪽으로 가서 위로 올라가는 막다른 주머니(x22~27, y10~13)의 오른쪽 위 구석. x=28이 벽이고 그 너머가 이미 익힌 윗길(29~33, 10~12)
  - 해석: 아래 길에서 "위로 가면 된다"는 습관이 엉뚱한 주머니로 이끌고, 구석에선 화면이 그대로라 같은 행동을 반복함 (관찰에 기억이 없음). 전선이 정확히 AC3가 못 넘은 자리에 와서 생긴 현상
  - 실제 입구 판: 풀숲 출구 근처(진행 약 25)까지 감. (44,10~11)에서 왼쪽 벽(x=43 열)을 미는 모습도 보임
- 학습 중 관찰 2 (16만, 전선 67): **제자리 회전** (사용자 관찰 "팽이처럼 돎")
  - 원인은 조작 방식: `GoldEnv`는 버튼을 8프레임만 누름 → 보고 있는 방향과 다른 방향이면 **몸만 돌고 안 걸음** (같은 방향을 한 번 더 눌러야 걸음. 직접 확인: left(방향 전환) → left(이동))
  - 전선 판 4번, 전체 1,909걸음 분류: **방향만 바꿈 56%**, 실제 이동 17%, 같은 방향으로 벽 밀기 9%, A/B 19%
  - → 아까 "(27,10)에서 벽 밀기"의 대부분도 실은 회전이었음. 방향을 자주 바꾸는 확률적 정책은 걸음의 절반 이상을 회전에 씀
  - 이 실험만의 문제가 아니라 **A2 이후 모든 실험에 같은 조건**이었음 (B2가 최단 103걸음에 약 140걸음 걸린 것도 일부는 이것일 수 있음)
  - 실험 도중이라 안 고침. 후보: 방향 버튼을 16프레임 누르기(`build_segment`의 BFS와 같은 방식) → "방향 버튼 1번 = 1칸". 환경 변경이라 별도 실험으로
- 학습 중 상황 (17만): 전선 67 (58에서 약 2만, 64에서 약 2.5만 스텝 머물다 넘어감). 전선 구간 도착률 46~56%. 전선 판 전멸이 36~67%로 늘어남 (턱 줄 아래 길 근처 풀숲에서 오래 헤매는 듯). 실제 입구 도착 0%
- 실행 메모: 학습 시작 직후 라이브만 고치고(전선 위치에서 시작, 1만 스텝마다 `live.zip`) `--resume`으로 다시 이어감. 환경/보상/커리큘럼 규칙은 그대로라 실험 조건은 같음
- 학습 중 관찰 3 (수풀): 19.7만 모델로 15판 → 전투 난 칸(= 수풀) 위에서 전선 판 걸음의 90%, 실제 입구 판 73%를 씀 (최단 경로는 103칸 중 11칸). 걸음의 절반 가까이가 (38~40, 14~15) 수풀 주머니 몇 칸. 전선(35,16)보다 동쪽이고 위는 턱이라 막다른 곳
  - 추정: 윗길에서 배운 "동쪽으로 가다 x=40에서 북쪽"을 화면이 비슷한 아랫길에서 반복 (확인 안 함)
  - 수풀을 좋아한다기보다, 도착 보상만 있어서 수풀에 **무관심** + 갇힌 곳이 수풀 → 전투가 쌓여 전멸
  - 결정: 수풀/전투/전멸에 벌점 안 줌 (레벨업 안 하는 정책이 될 위험). 갇힘을 고치는 쪽으로 (progress/README 원칙)
  - 그 뒤 학습 막판에 **스스로 풀림**: 전선 판 전멸 88%(20.9만) → 0%(23.4만~), 전투/판 7.4 → 2.5, 전선 구간 도착률 17% → 52% → 마지막 롤아웃에 전선 73 → 76
- **결과** (250k, 전선 76 = (38,15) 근처. 실제 시작 상태 진단, 위치당 25판, 체크포인트별)

- **판정**: 사전 기준 두 번째 ("전선 70 이상, 입구 도착 30% 미만 → 500k 연장")
- **해석**
  - **경로 전선은 U턴을 넘었음** (AC3 약 50 → DEMO 76). 턱 줄 아래 길, 수풀 주머니까지 통과 → AC3 정체는 "좌표 근처 = 다음 단계" 가정 탓이었다는 추정을 지지
  - **실제 입구 실력은 학습할수록 오히려 나빠짐** (진행 p50 38 → 10). 입구 쪽 27걸음(수풀 지대, 출구)은 아직 연습 대상이 아니었고, 실제 입구 판(10%)은 보상이 늘 0이라 그 근처 행동을 잡아주는 신호가 없음 → 다른 곳을 배우는 부수 효과로 이리저리 바뀜. 100k의 38은 우연에 가까움
  - → AC2, AC3와 같은 결론: **실력은 연습한 범위(전선 안쪽)에만 있고 바깥으로 번지지 않음**. 입구 도착은 전선이 입구에 닿아야 생길 것
  - 실제 입구 판 전멸(72~84%)은 아직 안 배운 수풀 지대(x44~53)에서 헤매다 쓰러지는 것
  - 비계 명시: 전선이 넘은 건 시연 경로(BFS) 덕분이고, 각 지점에서 걷는 법(동쪽 U턴, 수풀 주머니 탈출 포함)은 도착 보상만으로 RL이 배움
