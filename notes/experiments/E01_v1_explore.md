# v1_explore

> 실험 기록 (가설, 판정 기준, 결과, 해석). 공통 조건은 `notes/04_experiments.md`

- **보상**: 새 칸 0.1 / 새 맵 1.0 / 배지 100
- **가설**: 탐험 보상만으로 집 밖(연두마을)까지는 나갈 것
- **학습량**: 1,004,700스텝, 약 1시간. 615k에서 실수로 한 번 중단됐고, `--resume`으로 이어서 학습함
- **결과** (TensorBoard. 첫 기록 12k → 마지막 5개 기록 평균)
  - ep_rew_mean: 11.1 → 39.2
  - game/visited_tiles: 94 → 342 (최고 362)
  - game/visited_maps: 2.83 → 6.3 (553k에서 이미 최고 7 도달)
  - game/badges: 0
  - train/entropy_loss: -1.79 → -0.30 (행동이 거의 굳음)
  - train/explained_variance: 마지막 구간 0 근처에서 출렁임
- **행동 관찰** (`train.progress_map`, `train.analyze`, 전투 플래그 측정)
  - 집 2층/1층, 연두마을, 연구소, 옆집, 공박사 집, 29번도로 입구 = 시작 지점 근처 7개 맵을 다 훑는 법은 배움
  - 600k 이후로는 한 판의 절반(약 1000스텝)을 29번도로에서 보냄
  - 그런데 29번도로에서는 항상 **x=44에서 멈춤**. 왼쪽은 절벽 경계, 위는 나무라 돌아가는 길을 찾아야 하는 지점 (게임 화면 캡처 — 저작물이라 저장소에 안 올림, 로컬 `notes/img_local/route29_x44.png`)
    - **정정 (05 진단)**: 막다른 곳이 아니었음. 아래로 6칸 풀숲을 내려가면 (43,14)로 빠져나감. 막힌 원인은 기억이 아니라 마을 복귀 습관 + 풀숲 전투 비용
  - 야생 전투는 거의 안 일어남. final 모델로 4판 돌렸을 때 0번, 레벨은 5 그대로
    (처음엔 잘못된 플래그 D21B로 재서 "가끔 전투함"으로 나왔는데, 그건 대화창이었음. D1D3으로 다시 잼)
  - 참고: 무작위로 버튼을 누르면 야생 전투 하나에 약 750스텝을 씀 (메뉴 헤매기, 게임 화면 캡처는 저장소에 안 올림, 로컬 `notes/img_local/random_battle_strip.png`)
  - 이동 지도: `img/v1_explore_progress.png`
- **해석**
  - 탐험 보상은 의도대로 작동함. 랜덤 대비 칸 약 3.6배, 맵 약 2.2배
  - 다만 550k 이후로는 거의 정체됨. 가까운 칸 보상을 다 먹은 뒤로는 새 보상을 찾는 방법이 없음
  - 관찰이 화면 한 장뿐이라 "어디를 가봤는지" 모름 → 막다른 곳에서 돌아가는 길을 찾는 계획을 세울 수 없음
  - 엔트로피도 크게 떨어져서, 우연히 새 길을 발견할 확률도 낮아짐
- **다음에 바꿀 것**: 정체 원인을 두 갈래로 나눠서 확인
