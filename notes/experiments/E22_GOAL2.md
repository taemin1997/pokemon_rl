# GOAL2_route29 (GOAL1 + 은닉층 256-256)

> 실험 기록 (가설, 판정 기준, 결과, 해석). 공통 조건은 `notes/04_experiments.md`

- **왜**: GOAL1(E21)은 정방향 0%, 목표 사용이 체크포인트마다 100% ↔ 18%로 출렁이다 한 방향으로 쏠림. 원인: 은닉층 없이 화면 특징 + 목표를 선형으로 합쳐서, 목표가 화면과 엮이지 못하고 상수 쏠림만 줄 수 있었음
  - 초안(10-08 11:20)은 "+기억"이었으나 GOAL1 판정 후 변경: 기억도 같은 선형 구조라 이 문제를 못 고침, 판 시작 때 기억이 비어 있어 출발점 이탈에도 도움 안 됨
- **바꾼 것**: 신경망만. 화면 특징 512 + 목표 96 → **은닉층 256 → 256** (tanh, 정책/가치 각각) → 행동/가치 (`--hidden 256,256`). 파라미터 106만 → 150만. 나머지 GOAL1과 같음 (`route29_bidir_lat`, `goal_only`, tile, 50만, 시드 0, 기억 없음)
  - **조건 차이 명시**: GOAL2는 커리큘럼 난수 시드 연결 후 (10-08 재현성 수정). 학습 내용을 바꾸는 변경은 아니지만 해석 때 함께 적음. 콜백 누적 도착률 결함은 그대로 (따로)
  - **구조 확인**: 은닉층은 화면 특징 512와 목표 96을 이어 붙인 **뒤**에 들어감 (첫 층 `Linear(608, 256)`) → 화면 × 목표 상호작용 가능. 목표만 따로 MLP로 처리해 마지막에 더하는 방식이면 GOAL1과 같은 상수 쏠림 한계가 남음
- **가설**: GOAL1 실패가 "목표를 화면과 엮을 수 없는 구조" 때문이면, 은닉층이 있으면 목표 사용이 안정적으로 유지되고(체크포인트마다 분기점 바뀜 높음) 두 방향 모두 정체 지점을 넘음
- **판정 기준 (결과 보기 전, 10-08 11:40)**
  - 주: 정방향 start/S2/S3 ≥ 80%, 반대 방향 start ≥ 80% (`train.report`)
  - 목표 사용: 최종 분기점 바뀜 ≥ 50%, **20/30/40만 체크포인트도 ≥ 50%** (GOAL1처럼 출렁이지 않는지)
  - 학습 중: 두 전선 입구 도달 (GOAL1 52/103, 58/72에서 정체)
  - 부분 성공 (목표 사용은 안정, 도착 미달) → 정체 지점 원인은 구조가 아님 → 기억(GOAL3), 환경 배분, 예산
  - 결과별 다음 (외부 검토 반영):
    | 결과 | 다음 |
    |---|---|
    | 양방향 성공 + 분기점 통과 | 시드 재현 → 구간 통합 |
    | 분기점 통과, 도착 부족 | U턴/혼동 통로 분석 → 기억(GOAL3) 또는 커리큘럼 개선 (누적 평균 → 최근 판/EMA) |
    | 목표 반응은 늘었지만 맞는 방향 부족 | 목표와 화면의 결합 방식 검토 (결합 위치, FiLM 등) |
    | 목표 반응 거의 0 유지 | 목표 입력 전달, 구조, 학습 신호부터 재검증 |
  - 실패해도 바로 포기하지 않음: **아주 짧은 양방향 구간**에서 목표만 바꿔 정반대 행동을 배우는지 먼저 확인 (실패 → 구조/목표 전달 문제, 성공 → 긴 구간의 탐험/커리큘럼 문제)
  - 벽 고집은 목표 조건화와 별개 문제 → GOAL2 성공 후에도 남아 있으면 목표 조건화 실패로 해석하지 않음
- **비교**: GOAL1 (같은 report), LAT1 (정방향 기준선)
- **실행**
  ```
  uv run python -m train.train_ppo --env route29_bidir_lat --reward goal_only --move tile --goal --hidden 256,256 --steps 500000 --name GOAL2_route29
  ```

- **판정**: 주 기준 ✅ (정방향 96%, 반대 100%), 두 전선 입구 도달 ✅, 체크포인트 20/30/40만 분기점 바뀜 ≥ 50% ✅ (62/72/51), 최종 분기점 바뀜 ≥ 50% ❌ (41%) → **주 기준 통과, 보조 기준 하나 미달. 정책 하나가 같은 도로를 목표에 따라 양방향으로 감**. 일반화(경로 밖, 빼둔 지역, 혼동 통로)도 LAT1보다 높음
- **해석**
  - 한 걸음 시험(분기점 바뀜, 두 목표 모두 맞음)은 후반에 나빠 보였지만(30만 51% → 50만 28%) 실제 플레이는 경로 밖/빼둔 지역/혼동 통로 94~100% → 첫 걸음이 최단 방향이 아니어도 몇 걸음 안에 바로잡음. **한 걸음 시험은 "목표를 쓰나" 확인용이지 실력의 대리 지표로는 약함**. 13:50의 "후반에 목표 구분이 약해짐" 해석은 과했음 (정정)
  - GOAL1 대비: 같은 설정에 은닉층만 추가 (+커리큘럼 시드 연결) → 0% → 96~100%. 다만 "은닉층 덕"은 GOAL1b(은닉층 없음 + 수정 코드) 대조로 확인 필요 (GOAL1도 한 걸음 시험상 목표는 꽤 썼음)
  - 혼동 통로 100%: 양방향 학습이 그 통로를 "반대 방향의 실제 경로"로 연습시킨 효과로 보임 (반대 방향 시연이 그 통로를 지나감)
  - 벽 고집은 54%로 그대로/약간 증가 → 목표 조건화와 별개 문제 (외부 검토와 같은 판단)
  - 시드 1개 → 핵심 결론이라 재현 필요
- **다음**: ① GOAL2 시드 1 재현 (수정 코드: 시드 연결 + 리셋 첫 관찰) ② (선택) GOAL1b 대조 ③ 구간 통합 (연두마을 + 29번도로 양방향 + 무궁시티를 모델 하나로, 중간 목표/판 종료 분리 설계)

- **학습 중 관찰 (10-08 12:20, 16만)**: **반대 방향 전선이 15만 전에 입구 도달** (GOAL1은 58에서 끝까지 정체). 정방향 55 (U턴 근처), 폭 4
  - 목표 바꿔치기 (환경 수정 후): 5만 79% / 10만 82% / 15만 59% 분기점 바뀜, 맞는 방향 정방향 72~74%, 반대 64~72% (GOAL1 30만 62%, 67/56%)
  - 해석 (잠정): 은닉층 효과는 "목표를 쓸 수 있게 함"보다 "양방향 동시 학습을 훨씬 빠르게 함"에 가까움. GOAL1도 목표는 꽤 썼음 (E21 정정)
  - 주의: 이 학습은 리셋 첫 관찰 버그 수정 전 코드로 돌고 있음 (판당 첫 걸음만 영향). 수정 후 실험과 비교할 때 명시
- **해석 보류 메모 (10-08 12:30, 사용자와 논의)**: "은닉층이 없어서 목표를 못 씀"은 기각에 가까움 (GOAL1 분기점 56~62%). 남은 질문은 "전선이 왜 멈췄나". 후보: 신경망 용량(은닉층), 시드 운(시드 1개씩, LAT1도 시드 간 입구 도달 4만 스텝 차이), 실험 간 다른 변경(커리큘럼 시드 연결), 콜백 누적 평균
  - 가르는 대조 실험: **GOAL1b** = GOAL1 설정(은닉층 없음) + 수정된 코드(시드 연결, 리셋 첫 관찰 수정). GOAL1b도 입구 도달 → 은닉층 무관 / 또 정체 → 은닉층이 학습 효율에 영향. GOAL2 결과 보고 결정
