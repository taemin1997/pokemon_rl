## 가설 (측정 전)
- **H1 목표 무시**: 적응 뒤 정책이 X+1 상태에서 목표 정보(goal 벡터)를 덜 씀 → X의 목표(이미 도착한 맵) 쪽 행동을 함
- **H2 경계 화면 간섭**: X의 마지막 걸음들 (X+1 입구 바로 앞 화면)과 X+1의 첫 걸음들 화면이 비슷한데 목표·행동이 다름 → X를 세게 학습하면 X+1 입구 근처 행동이 바뀜
- **H3 표본 부족**: 새 구간 가중치 3 + 판이 길어진 X+1은 학습 중 판 수가 줄어 (s0 r1 route29 판 수 로그 구간당 30 → 1~9) 고칠 기회가 적음 → 무너진 뒤 회복 못 함 (원인이 아니라 회복 실패 설명)
- 셋 다 아닐 수 있음 (가치 함수 등). 섞여 있을 수도 있음

## 분석 (학습 없음, 가벼운 측정)
- **F1 시점**: 학습 곡선 전체 (real_goal, seg_eps) + 체크포인트 5만 (`ppo_49998_steps.zip`)으로 route29·cherrygrove diagnose 25판 (시계 고정). 판단: 오프라인 도착률이 학습 중 real_goal과 같은 방향이면 (둘 다 무너졌거나 둘 다 멀쩡) 학습 중 신호를 감지기로 쓸 수 있다고 봄
- **F2 행동 변화 위치**: X+1 시연 경로(BFS) 위 상태마다 M2B vs 적응 모델의 행동 확률 차이 (총변동거리 TV). 큰 상태가 어디인지 (입구 근처 몇 칸 안? 전 구간?)
- **F3 목표 민감도 (H1)**: 같은 상태에 목표 벡터만 X+1 목표 ↔ X 목표로 바꿔 넣고 행동 확률 차이 (TV)를 모델별로 비교
  - H1 지지: 적응 모델의 목표 민감도가 M2B의 절반 미만이고, 적응 모델의 X+1 행동이 M2B에 X 목표를 넣었을 때 행동과 더 가까움
  - H1 기각: 목표 민감도가 M2B와 비슷 (0.5배 이상)
- **F4 입구 근처 (H2)**: F2의 TV가 X+1 입구에서 5칸 안 상태에 몰려 있나 (TV 상위 10개 상태 중 비율). 지지: 절반 이상이 입구 5칸 안 + 화면이 X의 마지막 화면과 가까움
- 판정은 시드별로 따로. 2시드 × 1~2개 사례라 결론은 "가설 수준"으로 적음
