## 실험군 (A 대비 하나씩만 바꿈)
| 군 | 바꾼 것 | 검증 가설 |
|---|---|---|
| **A** 기준선 | 없음 (E26 r1 다시 학습) | 망각 재현 (E26 r1은 route29 8%·40%) — 같은 코드 버전에서 한 번 더 |
| **B** 혼합 비율 | 새 구간 가중치 3 → 1 (새 구간 비중 약 12.5% → 4.5%) | 옛 구간을 더 많이 연습하면 보존되나 (save-state 혼합은 A에도 이미 있음) |
| **C** 전체 KL 규제 | 손실에 β·KL(π_M2B ‖ π)를 **모든 rollout 상태**에 더함 | 정책 변화 자체를 제한하면 보존되나 |
| **D** 확신 상태만 KL | 같은 β·KL을 **고정된 상태 묶음**에만: 16구간 시연 경로 594칸 중 M2B 최빈 확률 ≥ 0.8인 칸 (E29 K 규칙의 앞 절반, 뒤집힘은 학습 전엔 모름) | 소수 결정적 상태만 지켜도 되나 |
- β = 1.0 (C·D 같게, 결과 보기 전 고정. 조정 안 함). KL은 PPO 손실에 더하는 항, 옛 정책 M2B는 고정
- C·D는 새 코드 (`train/train_ppo.py`에 `--anchor-model`, `--anchor-coef`, `--anchor-states` — 기본 꺼짐, 꺼짐이면 예전과 같음을 짧은 학습으로 확인)
- D의 상태 묶음은 BFS 시연 경로에서 뽑음 (트랙 B 정보). 트랙 A로 가려면 Go-Explore 경로·성공 판 궤적으로 바꿔야 함 — E31 몫

## 판단 기준 (확정)
- **새 구간 유지**: E-lab 실패 ≤ 20% **그리고** A 대비 +10%p 이내 (못 배우면 보존해도 소용없음)
- **보존**: 16구간 모두 길 찾기 실패 증가 (M2B 대비) < +10%p (E26 운영 기준과 같음)
- 군별 판정 (시드별): 둘 다 만족 = **성공** / 새 구간만 = **보존 실패** / 보존만 = **학습 방해**
- 비교: D가 성공이고 C와 보존이 비슷하면 (실패 증가 최악값 차이 ≤ 10%p) "소수 상태만 지켜도 됨" 지지
- 25판이라 ±2표준오차 ≈ 최대 ±20%p → 경계 근처 (+5 ~ +15%p) 구간은 그 구간만 50판으로 다시 잼 (미리 정한 규칙)
- A가 망각을 재현 못 하면 (16구간 모두 +10%p 미만) 비교 무효 → 보고 후 재설계
