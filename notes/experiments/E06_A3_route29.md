# A3_route29 (A2 + 도착 보너스, BFS 없음)

> 실험 기록 (가설, 판정 기준, 결과, 해석). 공통 조건은 `notes/04_experiments.md`

- **바꾼 것**: 보상만 (`--reward A3_goal`): A2 보상(새 칸 0.1, 새 맵 1.0) + 무궁시티 도착 +10. 거리 보상 없음
- **왜**: B의 도착(64~72%)이 BFS 거리 신호 덕분인지, "도착하면 칭찬"만으로도 U턴을 넘는지 가르기 (RL 중심 원칙)
- **가설**: U턴을 넘는 데 필요한 건 "방향 신호"라서, 도착 보너스만으로는 부족할 것 (우연히 한 번 도착해야 보너스를 배움)
  - 반대로 A2가 최대 79까지 간 적이 있으니, 가끔 도착 → 보너스로 강화되는 경로가 생길 수도 있음
- **판정 기준** (250k 후 `train.diagnose route29`, ±10%p 오차 감안)
  - 도착률 ≥ 30% → BFS 없이도 됨. 거리 보상은 "속도 향상" 정도의 역할 → 이후 구간은 A3 방식이 기본
  - 도착률 0~10%, 진행은 A2 수준 (약 47) → 방향 신호가 필수. B 계열 유지, 일반화 테스트로 "외웠나"를 확인
  - 그 사이 → 둘 다 남기고 일반화 테스트에서 비교
- 학습 중 볼 지표: `game/reached_goal` (0에서 움직이는 순간), `game/progress` (A2는 250k에서 약 46)
- **결과** (250k, `final.zip`, `train.diagnose`, 위치당 25판)

| 시작 | 도착률 | 진행 평균/최대 | 이탈 | 전멸 | 전투/판 |
|---|---|---|---|---|---|
| start (S1) | 0% | 47.9 / 53 | 8% | 0% | 3.8 |
| S2 | 0% | 42.1 / 43 | 8% | 20% | 4.5 |
| S3 | 0% | 46.0 / 47 | 0% | 4% | 3.6 |

  - 학습 중에도 도착 0 (25만 스텝 동안 한 번도 도착 못 함)
- **판정**: 도착률 0% → **방향 신호(거리 보상)가 필수** (사전 기준 두 번째 경우)
- **해석**
  - 진행이 A2와 거의 같음 (약 46~48). 도착 보너스는 U턴 구간 앞의 벽을 넘게 해주지 못함
  - 이유: 보너스는 **한 번이라도 도착해야** 학습 신호가 됨. 탐험 보상만으로는 U턴 너머까지 가는 판이 생기지 않아서, 보너스가 존재하는 걸 알 기회가 없었음
  - → 이 예산(250k)에선 "탐험 + 결과 보상"만으로는 부족하고, 중간 과정을 알려주는 신호(거리 보상)가 결정적
  - BFS 기여도 정리: A2 / A3 (BFS 없음) 도착 0% → B (BFS 거리 보상) 64~72%
- **다음**: B 계열 유지. "외웠나 vs 배웠나"는 멀티 구간 + 새 구간 일반화 테스트로 확인
  - BFS 없이 넘는 방법(새 칸 보상 개선, 기억, Go-Explore식 재시작)은 RL 중심 연구 과제로 남김
