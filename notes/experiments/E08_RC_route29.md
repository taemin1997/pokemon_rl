# RC_route29 (역방향 커리큘럼, 거리 보상 없음)

> 실험 기록 (가설, 판정 기준, 결과, 해석). 공통 조건은 `notes/04_experiments.md`

- **바꾼 것**: 시작 위치 분포 + 보상. 거리표는 학습에 전혀 안 씀 (`--env route29_rc --reward goal_only`)
  - 보상: 무궁시티 도착 +10만 (새 칸, 새 맵, 거리 보상 전부 끔) → 가장 드문 보상
  - 시작: 10%는 실제 입구(S1), 90%는 후보 풀. 씨앗 = 목표 도착 상태에서 무작위 4~12걸음 (목표 1~4걸음 앞)
  - 후보 성공률 > 80%면 거기서 무작위로 더 걸어 새 후보 추가. 성공률 20~80% 후보 우선. 풀 최대 64개 (환경마다 따로)
  - 무작위 걸음이라 정답 방향 정보 없음. 거리표는 시작 위치 기록(start_dist, 분석용)에만 씀
- **구현 확인**: 씨앗 16개 모두 목표 1~4걸음 앞. 무작위 행동으로도 후보 시작 판 도착 63%. 6천 스텝 시험 학습에서 후보 시작 도착 85~88%
- **비교 대상**: A3 (도착 보상 계열, 입구에서만 시작) 0% / B (거리 보상) 64~72%
- **가설**: A3가 실패한 이유가 "도착을 한 번도 못 해서 보상이 학습 신호가 안 된 것"이라면, 목표 근처부터 시작하면 신호가 생기고 그게 뒤로 퍼져서 입구에서도 도착하게 될 것
- **판정 기준** (250k 후 `train.diagnose route29`, 실제 시작 S1/S2/S3에서)
  - S1 도착률 ≥ 30% → **정답 지도 없이 U턴을 넘음** (프로젝트 분기점 통과)
  - 도착률 낮지만 `start_dist`가 U턴 너머(약 50 이상)까지 넓어짐 → 방향은 맞음, 학습량 부족 → 연장
  - `start_dist`가 U턴 앞에서 멈춤 → 커리큘럼 확장이 U턴에서 막힘 (무작위 걸음으로는 U턴 반대편 후보가 안 생김) → 확장 방식 재설계
- **볼 지표**: `game/start_dist` (커리큘럼 전선이 얼마나 멀어지나), `game/real_goal` (실제 입구 시작 판의 도착률), `game/rc_pool`
- **해석 주의**: 무작위 걸음 확장은 확산이라 느림 (거리 √n). U턴 같은 좁은 통로 너머로 후보가 넘어가는 데 시간이 걸릴 수 있음
- **결과**: ❌ 67k에서 중단 (사전 기준 세 번째: 커리큘럼 전선이 멈춤)
  - 후보 시작 판은 완벽하게 익힘 (도착 84~90%, 7걸음 만에 도착). 후보 수 16 → 42
  - 그런데 연습 시작 위치가 6만 스텝 동안 **목표에서 약 9걸음 안쪽**에 머묾 (입구 103, U턴 약 50)
  - 실제 입구 시작 판 도착 0%
  - 원인: 무작위 4~12걸음 확장은 확산이라 거의 안 멀어짐 + 같은 좌표에 후보가 계속 쌓임 (걱정했던 "확산이 느림"이 그대로 나타남)
