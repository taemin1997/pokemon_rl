# ZS30 (학습 없음): GOAL2를 처음 보는 30번도로에 그대로 — 트랙 A 첫 의존도 검증

> 실험 기록. 외부 검토(10-08) 제안: 비계 제거보다 **비계 의존도 검증**이 먼저

- **질문**: BFS 시연으로 배운 GOAL2가, 시연도 학습도 없이 처음 보는 맵에서 길을 찾나?
- **GOAL2 관측 확인**: 화면(흑백 72×80) + 목표 맵 원핫(96)만. BFS 거리/방향/좌표/지도 없음. 보상 = 도착 +10 하나. BFS는 학습 시작 위치(시연, 경로 밖 상태)와 진단에만
- **함정**: 목표가 원핫이라 **학습 때 못 본 목표 맵은 의미 없는 입력**. GOAL2가 본 목표 = 무궁시티(26,3), 연두마을(24,4)뿐
  - 주 시험 = `route30_rev` (할아버지 집 앞 → 무궁시티): 목표는 본 것, 맵은 처음 → 순수한 "새 맵 길 찾기"
  - 대조 = `route30` (30번도로 입구 → 할아버지 집): 목표도 처음 → 실패해도 원인 구분 불가 (참고용)
  - 기준선 = random, LAT1 (목표 정보 없음, 29번도로 정방향만 배움)
- **측정**: `train.diagnose route30_rev` / `route30`, 25판 (최대 512걸음), 도착률, 진행 p50/p90, 이탈
- **판정 기준 (실행 전 10-08 15:55)**
  - route30_rev 도착 ≥ 50% → **새 맵으로 전이되는 길 찾기 능력 있음** (강한 증거)
  - 10~50% 또는 진행 p50이 random보다 확실히 큼 → 부분 전이 (방향 감각은 있으나 막힘)
  - random 수준 → 지금 능력은 학습한 맵에 묶여 있음 → 트랙 A 다음 실험(시연 없는 추가 학습 B, 처음부터 C)으로 전이 효과를 스텝 수로 잼
- **다음 (외부 검토 표)**: A(이 실험) → B GOAL2 초기 + 시연 없이 30번도로 학습 → C 랜덤 초기 + 시연 없이 → D GOAL2 초기 + 시연 있음. 같은 평가
- **결과** (10-08 16:05, 25판)

| 구간 | GOAL2 | LAT1 | random |
|---|---|---|---|
| route30_rev (목표 본 것, 맵 처음) | **0%**, 진행 p50 1 / p90 2 | 0%, 2 / 3 | 0%, 4 / 9 |
| route30 (목표도 처음, 대조) | 0%, **이탈 100%** | - | 0%, 이탈 88% |

- 추적 (150걸음): route30_rev에서 GOAL2는 왼쪽 38 / **위 93** / 아래 9 → (9,6)에서 위쪽 벽 130걸음. 무궁시티는 남쪽(아래)인데 29번도로의 "무궁시티 = 서쪽/위" 습관대로 감. route30은 첫 걸음 아래로 → 무궁시티로 이탈
- **판정**: random 이하 → **지금 능력은 학습한 맵에 묶여 있음**. 목표 원핫을 "그 맵으로 가는 길을 찾아라"가 아니라 학습 맵 지형에 묶인 방향 습관으로 익힘
- **해석**: GOAL2의 일반화(빼둔 지역 100%)는 "학습한 맵 안"의 일반화. "처음 보는 맵에서 길 발견"은 안 됨 (외부 검토 표의 미검증 항목 → 실패로 확인). 성과를 과대평가하지 않게 하는 결과
  - 목표 표현 문제도 드러남: 원핫은 새 목표로 일반화 불가 → 트랙 A 과제
- **다음 (트랙 A)**: B0 GOAL2 초기 + 실제 출발만 (순수 RL 확인) / B GOAL2 초기 + Go-Explore 경로 / C 랜덤 초기 + Go-Explore / D GOAL2 초기 + BFS 시연. 지표 = 같은 평가에서 80% 도달 스텝. 대상 route30_rev (목표 본 것)
